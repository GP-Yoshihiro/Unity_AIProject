# Feature Specification: 神経衰弱（Memory Match）

**Feature Branch**: `20261124-memory-match-sdd`

**Created**: 2026-11-24

**Status**: v1.1（v1.0: M1〜M6 ／ v1.1: コンボ A1〜A4、対戦 B1〜B7 を追記 ／ v1.2: 難易度 D1〜D3、対戦のトランプ化 B8・スコア順位 B4 改訂）。人間の回答は interview.md に記録。初稿全文の人間レビューは未実施

## User Scenarios & Testing *(mandatory)*

### User Story 1 - めくって、ペアをそろえる (Priority: P1)

プレイヤーとして、めくったカードを覚えてペアをそろえたい。

**Why this priority**: ゲームの中心で、単独で遊べる。

**Independent Test**: 開始して2枚ずつめくり、成立とミスの結果を確認する。

**Acceptance Scenarios**:

1. **AS-01 / M1 初期状態** — **Given** 開始直後, **When** 何も入力しない, **Then** 12枚（6ペア）すべて裏向き、成立0・ミス0・スコア0で、クリアもゲームオーバーも表示しない
2. **AS-02 / M2 めくる** — **Given** 全て裏向き, **When** 矢印でカーソルを動かしSpaceを押す, **Then** その1枚だけ表になる。2枚目までめくれ、3枚目はめくれない
3. **AS-03a / M3 成立** — **Given** 1枚表, **When** 同じ絵柄の2枚目をめくる, **Then** 即座に成立し2枚は表のまま、成立+1、スコア+100
4. **AS-03b / M3 ミス** — **Given** 1枚表, **When** 違う絵柄の2枚目をめくる, **Then** 即座にミス+1、スコア-10（0未満にならない）。2枚は見え続け、次のSpaceで両方裏に戻る。そのSpaceでは新しいカードをめくらない
5. **AS-04 / M4 二重防止** — **Given** 成立済み、または表のカードにカーソルがある, **When** Spaceを押す, **Then** 状態は変わらない（ミス後に裏へ戻すSpaceを除く）。1枚目自身を2枚目にも選べない

---

### User Story 2 - 勝敗が決まる (Priority: P2)

プレイヤーとして、全部そろえた達成や、失敗しすぎた終わりを知りたい。

**Why this priority**: 緊張感と区切りを与える。

**Independent Test**: 6ペアの成立と5回のミスをそれぞれ行う。

**Acceptance Scenarios**:

1. **AS-05a / M5 クリア** — **Given** 5ペア成立, **When** 最後のペアを成立させる, **Then** クリアを表示し、以後R以外の入力を受け付けない
2. **AS-05b / M5 ゲームオーバー** — **Given** ミス4回, **When** 5回目のミスをする, **Then** 即座にゲームオーバーを表示し、最後の2枚は表のまま、以後R以外の入力を受け付けない

---

### User Story 3 - やり直す (Priority: P3)

プレイヤーとして、いつでも新しい配置でやり直したい。

**Why this priority**: 繰り返し遊ぶために要る。

**Independent Test**: 途中、クリア後、ゲームオーバー後のそれぞれでRを押す。

**Acceptance Scenarios**:

1. **AS-06 / M6 再開** — **Given** 途中または終了後, **When** Rを押す, **Then** 配置をシャッフルし直し、全カード裏向き・成立0・ミス0・スコア0になり、終了表示が消えて再び遊べる

### User Story 4 - 連続成立で高得点（コンボ） (Priority: P4)

1人用のプレイヤーとして、連続で当てたときに得点が伸びてほしい。

**Why this priority**: 記憶の手応えを増す追加。M1〜M6が成り立った上で足す。

**Independent Test**: 連続で成立させた得点と、ミス後の得点を比べる。

**影響する既存条件**: M3（加算の値）、M6（初期化する値）

**Acceptance Scenarios**:

1. **A1** — **Given** n-1連続で成立, **When** 次も成立させる, **Then** スコアが 100×min(n, 5) 増える（1回目100、2回目200…、5回目以降500）
2. **A2** — **Given** 連続中, **When** ミスする, **Then** 連続数が0に戻る。減点は倍率によらず10
3. **A3** — **Given** 1人用, **When** 成立やミスで連続数が変わる, **Then** 画面の連続数も変わる
4. **A4** — **Given** 連続中または終了後, **When** Rを押す, **Then** 連続数が0に戻る

---

### User Story 5 - ペアを取り合って対戦する (Priority: P1)

プレイヤーとして、CPUや友だちとペアを取り合って勝敗を競いたい。

**Why this priority**: 必須条件「ペアでカードを取得できる」「二人以上で対戦（CPU戦含む）できる」。

**Independent Test**: 対CPUと対人を最後まで遊び、取得数と勝敗を確認する。

**影響する既存条件**: M1（開始前にモード選択が入る）、M3（対戦では各自に得点とコンボを付ける）、M5（対戦ではミス上限を使わない）、M6（同じモードと人数で再開）。1人用のM1〜M6は、モード選択後について変えない

**Acceptance Scenarios**:

1. **B1 モード選択** — **Given** 起動直後, **When** 上下で1人用／対CPU／対人を、左右で（対戦なら）人数2〜4を選びSpaceを押す, **Then** そのモードで始まる。対CPUは人間1人＋残りがCPU
2. **B2 取得** — **Given** 自分の手番, **When** ペアをそろえる, **Then** その2枚は自分の取得になり、取得ペア数+1、スコアは 100×min(連続数, 5) 増え、持ち主がカードに表示され、同じ人が続けてめくる
3. **B3 交代** — **Given** 自分の手番, **When** ミスする, **Then** その人のスコア-10（下限0）・連続数0。2枚が見え、次のSpaceで裏に戻って次の人の手番になる（最後の人の次は1人目）
4. **B4 勝敗** — **Given** 残り1ペア, **When** 取得される, **Then** 最終スコアの高い順に全員の順位を表示する。同点は同じ順位（1位が複数なら引き分け）。ミスが何回でもゲームオーバーにならない
5. **B5 CPU** — **Given** CPUの手番, **When** 待つ, **Then** CPUが自動でめくり、ミスなら自動で戻して交代する。CPUは裏の絵柄を知らず、誰かがめくったカードのうち直近4枚だけを記憶に使う。CPUの手番中、人間の矢印・Spaceは効かない
6. **B6 複数人** — **Given** 3人または4人を選択, **When** ミスが続く, **Then** 全員に順に手番が回る
7. **B7 再開と戻る** — **Given** 対戦中または終了後, **When** Rを押す, **Then** 同じモードと人数で、全員取得0・1人目の手番・新しい配置から始まる。Escでモード選択へ戻る（全モード共通）
8. **B8 トランプ** — **Given** 対戦を開始, **When** 盤面を見る・めくる, **Then** ジョーカーなしの52枚が裏向きで並び、スートと数字が見え、数字が同じ2枚（スートは問わない）がペアになる。26ペア取得で終了する

---

### User Story 6 - 難易度を選ぶ (Priority: P2)

1人用のプレイヤーとして、枚数の違う難易度を選びたい。

**Why this priority**: 追加の必須条件。EASYは従来の1人用と同じ。

**Independent Test**: 3つの難易度を開始し、枚数とミス上限を確認する。

**影響する既存条件**: M1・M5（枚数とミス上限はEASYの値。NORMAL・HARDは下表の値に読み替える）、M6（同じ難易度で再開）

| 難易度 | 枚数 | 並び | ミス上限 |
|--------|------|------|----------|
| EASY | 12枚（6ペア） | 4列×3行 | 5 |
| NORMAL | 16枚（8ペア） | 4列×4行 | 10 |
| HARD | 24枚（12ペア） | 6列×4行 | 20 |

**Acceptance Scenarios**:

1. **D1** — **Given** モード選択で1人用, **When** 左右で難易度を選びSpaceを押す, **Then** 表の枚数・並びで全て裏向きに始まる
2. **D2** — **Given** 各難易度, **When** 全ペア成立、またはミスが表の上限に達する, **Then** クリア、またはゲームオーバーになる
3. **D3** — **Given** 各難易度の途中または終了後, **When** Rを押す, **Then** 同じ難易度の初期状態に戻る

### Edge Cases

- モード選択では、選択は端で止まる。1人用の左右は難易度、対戦の左右は人数
- 対戦で全員のスコアが並んだ場合は全員1位

- カーソルが端のとき、外側への入力ではその場にとどまる
- スコア0でミスしたとき、0のまま
- 裏に戻すSpaceを待つ間のカーソル移動は可能。この間のRも有効
- 最後のペアの成立時は、クリアとなり次のSpaceを待たない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-01**: 開始時、6種の絵柄を2枚ずつ計12枚、4列×3行に裏向きで並べ、成立・ミス・スコアを0とすること（M1）
- **FR-02**: 矢印キーでカーソルを動かし（左上から開始、端で停止）、Spaceで1枚めくること。1ターン2枚まで（M2）
- **FR-03**: 2枚めくったら即座に絵柄を比較し、成立（表のまま・+100）かミス（ミス+1・-10、下限0）かを判定すること。ミスの2枚は次のSpaceで裏に戻り、そのSpaceは戻すだけとすること（M3）
- **FR-04**: 成立済み・表向きのカードを選んでも状態を変えないこと（M4）
- **FR-05**: 全ペア成立でクリア、ミス5回でゲームオーバーとし、以後R以外を受け付けないこと。ゲームオーバー時の最後の2枚は表のままとすること（M5）
- **FR-06**: Rで、いつでも配置をシャッフルし直し、FR-01の初期状態（カーソルも左上）に戻ること（M6）
- **FR-07**: 通常は毎回ランダムな配置とし、設定でシードを固定できること。同じシードなら、開始時の配置もR後の配置の順も再現されること
- **FR-08**: 1人用で連続成立をコンボとして数え、n連続目の成立得点を 100×min(n, 5) とし、ミスとRで0に戻し、連続数を表示すること（A1〜A4）
- **FR-09**: 開始前に1人用／対CPU／対人と人数2〜4を選べ、Escで選択に戻れること（B1, B7）
- **FR-10**: 対戦では、そろえたペアを手番の人の取得とし、成立なら続行、ミスなら裏に戻した時点で次の人に交代すること（B2, B3, B6）
- **FR-11**: 対戦では各自に得点（+100×min(連続数, 5)、ミス-10、下限0）を付け、全ペア取得で終了して最終スコアで順位を付けること。同点は同順位、ミス上限は使わないこと（B2〜B4）
- **FR-12**: CPUは自動で手番を進め、公開されたカードのうち直近4枚の記憶だけで選ぶこと（B5）
- **FR-13**: 1人用は枚数の違う3つの難易度から選べ、枚数・並び・ミス上限を表のとおりとすること（D1〜D3）
- **FR-14**: 対戦はトランプ52枚を使い、同じ数字の2枚をペアとすること（B8）

### Key Entities

- **カード**: 絵柄（1人用: 難易度に応じた種類、色と記号で区別。対戦: スートと数字）、向き（裏／表／成立済み）、持ち主（対戦時）
- **プレイヤー**（対戦時）: 番号、人間かCPUか、取得ペア数
- **ゲーム**: モード、人数、手番、コンボ、成立数、ミス数、スコア、カーソル位置、進行状態

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: M1〜M6の全シナリオを、実際のキー入力だけで再現できる
- **SC-002**: プレイヤーは矢印・Space・Rの操作だけで、開始から終了、再開まで到達できる
- **SC-003**: 絵柄は、色が見分けられなくても記号で区別できる
- **SC-004**: 各シナリオの判定に、状態と画面の2種類の根拠がある
