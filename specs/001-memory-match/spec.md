## User Scenarios & Testing *(mandatory)*

### User Story 1 - めくって、ペアをそろえる (Priority: P1)

プレイヤーとして、めくったカードを覚えてペアをそろえたい。

**Why this priority**: ゲームの中心で、単独で遊べる。

**Independent Test**: 開始して2枚ずつめくり、成立とミスの結果を確認する。

**Acceptance Scenarios**:

1. **AS-01 / M1 初期状態** — **Given** 開始直後, **When** 何も入力しない, **Then** 12枚（6ペア）すべて裏向き、成立0・ミス0・スコア0で、クリアもゲームオーバーも表示しない
2. **AS-02 / M2 めくる** — **Given** 全て裏向き, **When** 矢印でカーソルを動かしSpaceを押す, **Then** その1枚だけ表になる。2枚目までめくれ、3枚目はめくれない
3. **AS-03a / M3 成立** — **Given** 1枚表, **When** 同じ絵柄の2枚目をめくる, **Then** 即座に成立し2枚は表のまま、成立+1、スコア+100
4. **AS-03b / M3 ミス** — **Given** 1枚表, **When** 違う絵柄の2枚目をめくる, **Then** 即座にミス+1、スコア-10（0未満にならない）。2枚は見え続け、次のSpaceで両方裏に戻る。そのSpaceでは新しいカードをめくらない
5. **AS-04 / M4 二重防止** — **Given** 成立済み、または表のカードにカーソルがある, **When** Spaceを押す, **Then** 状態は変わらない（ミス後に裏へ戻すSpaceを除く）。1枚目自身を2枚目にも選べない

---

### User Story 2 - 勝敗が決まる (Priority: P2)

プレイヤーとして、全部そろえた達成や、失敗しすぎた終わりを知りたい。

**Why this priority**: 緊張感と区切りを与える。

**Independent Test**: 6ペアの成立と5回のミスをそれぞれ行う。

**Acceptance Scenarios**:

1. **AS-05a / M5 クリア** — **Given** 5ペア成立, **When** 最後のペアを成立させる, **Then** クリアを表示し、以後R以外の入力を受け付けない
2. **AS-05b / M5 ゲームオーバー** — **Given** ミス4回, **When** 5回目のミスをする, **Then** 即座にゲームオーバーを表示し、最後の2枚は表のまま、以後R以外の入力を受け付けない

---

### User Story 3 - やり直す (Priority: P3)

プレイヤーとして、いつでも新しい配置でやり直したい。

**Why this priority**: 繰り返し遊ぶために要る。

**Independent Test**: 途中、クリア後、ゲームオーバー後のそれぞれでRを押す。

**Acceptance Scenarios**:

1. **AS-06 / M6 再開** — **Given** 途中または終了後, **When** Rを押す, **Then** 配置をシャッフルし直し、全カード裏向き・成立0・ミス0・スコア0になり、終了表示が消えて再び遊べる

### Edge Cases

- カーソルが端のとき、外側への入力ではその場にとどまる
- スコア0でミスしたとき、0のまま
- 裏に戻すSpaceを待つ間のカーソル移動は可能。この間のRも有効
- 最後のペアの成立時は、クリアとなり次のSpaceを待たない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-01**: 開始時、6種の絵柄を2枚ずつ計12枚、4列×3行に裏向きで並べ、成立・ミス・スコアを0とすること（M1）
- **FR-02**: 矢印キーでカーソルを動かし（左上から開始、端で停止）、Spaceで1枚めくること。1ターン2枚まで（M2）
- **FR-03**: 2枚めくったら即座に絵柄を比較し、成立（表のまま・+100）かミス（ミス+1・-10、下限0）かを判定すること。ミスの2枚は次のSpaceで裏に戻り、そのSpaceは戻すだけとすること（M3）
- **FR-04**: 成立済み・表向きのカードを選んでも状態を変えないこと（M4）
- **FR-05**: 全ペア成立でクリア、ミス5回でゲームオーバーとし、以後R以外を受け付けないこと。ゲームオーバー時の最後の2枚は表のままとすること（M5）
- **FR-06**: Rで、いつでも配置をシャッフルし直し、FR-01の初期状態（カーソルも左上）に戻ること（M6）
- **FR-07**: 通常は毎回ランダムな配置とし、設定でシードを固定できること。同じシードなら、開始時の配置もR後の配置の順も再現されること

### Key Entities

- **カード**: 絵柄（6種のうち1つ、色と記号で区別）、向き（裏／表／成立済み）
- **ゲーム**: 成立数、ミス数、スコア、カーソル位置、進行状態

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: M1〜M6の全シナリオを、実際のキー入力だけで再現できる
- **SC-002**: プレイヤーは矢印・Space・Rの操作だけで、開始から終了、再開まで到達できる
- **SC-003**: 6種の絵柄は、色が見分けられなくても記号で区別できる
- **SC-004**: 各シナリオの判定に、状態と画面の2種類の根拠がある
