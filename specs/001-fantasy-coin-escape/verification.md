## 検証中に見つけて直した問題

1. **入力アセット・設定アセットの参照が空になる**（Builder）: 入力アセットの書き出し直後の再インポートで、先に取得していたインスタンスが無効になり、Boot シーンの `GameInput.actions` と `GameDirector.config` が空で保存されていた。参照を設定する直前に読み直し、空なら例外にするよう修正。
2. **状態が JSON として読めない**: `GameDirector` に `Flow`（プロパティ）と `flow`（フィールド）があり、PowerShell の ConvertFrom-Json が大文字小文字の違いで失敗した。プロパティ名を `CurrentFlow` に変更。
3. **テストを開始できていなかった**: 前ブランチのシーン（未保存）が開いたままで `run_tests` が拒否され、`get_test_status` は前回の結果（BallCollect 5件）を返していた。runId を照合するようにし、空のシーンに切り替えてから実行。
4. **台座で保存できない位置があった**: 台座の当たり判定のため中心から1.9m以上離れてしまい、保存範囲1.8mに入れなかった。保存範囲を2.2mに変更。
5. **カメラの角度が浅く手前の壁にプレイヤーが隠れる**: オフセットを (0,16,−11) → (0,21,−8) に変更し、画像で確認。
