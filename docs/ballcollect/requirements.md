# BallCollect 要件

球を操作して床の上のアイテム5個を回収するゲーム。Unity 6.6 (6000.6.4f1) / unity-cli v0.19.1 で、AI が Editor を操作して作成・検証する。

- シーン: `Assets/Scenes/BallCollect.unity`
- 入力: Input System に統一する（旧 Input Manager の API は使わない）

## 基本仕様

| ID | 項目 | 条件 |
|----|------|------|
| B1 | 初期状態 | 床・球・カメラ・アイテム5個がある。回収数0、CLEARは表示しない |
| B2 | 移動 | WASDで移動。Wは+Z、Sは−Z、Dは+X、Aは−X。カメラは方向が分かる固定視点 |
| B3 | 回収 | 触れたアイテムが消え、回収数が1増える。同じアイテムで二重加算しない |
| B4 | クリア | 5個すべて回収したときだけCLEAR。回収途中では表示しない |
| B5 | 落下 | 位置・速度・回収数・アイテム・UIを初期化する。位置だけ戻す実装にしない |
| B6 | Rで再開 | 途中でもクリア後でも同じ初期状態へ戻る |

## 調整値

| 項目 | 値 |
|------|----|
| 床 | 20×20（Plane、scale 2,1,2）、原点中心 |
| 球 (Player) | 初期位置 (0, 0.5, −7)、青 |
| アイテム | 黄色のキューブ。X=0、Z=−4・−1・2・5・8（y=0.5） |
| 移動速度 | 5 m/s |
| 落下判定 | 球の y < −5 |
| カメラ | 固定。(0, 16, −18) から床中央を見下ろす。画面の上が+Z、右が+X |

## 追加ルール（第2コマ）: 30秒の時間制限

狙い: 制限時間を設けて、回収の順番に意味を持たせる。

| ID | 条件 |
|----|------|
| A1 | 残り30秒を表示し、プレイ中に減る |
| A2 | 未回収のまま0になったらTIME UP、移動停止 |
| A3 | 時間内に全回収したらCLEAR、時計は停止 |
| A4 | CLEAR後に時間切れへ変わらない |
| A5 | Rと落下で残り時間も30秒に戻る |

- 優先順位: 同じ更新で5個目の回収と時間切れが重なった場合は、回収完了（CLEAR）を優先する。
- 時間切れ中もRは効く。
- 影響する基本仕様: B4（CLEARで時計停止）、B5・B6（初期化範囲に残り時間とTIME UP表示を追加）。

## CLIで取得する状態

`GameManager` の `BallCollectGame` コンポーネントが次の値を公開する。

- `collectedCount` / `totalItems` / `isCleared` / `remainingTime` / `isTimeUp`

## 範囲外

敵、外部アセット、効果音、複数ステージ、ランキング、オンライン機能、動画収録、実行ファイルのビルド。後から「おまけ」として追加しない。
